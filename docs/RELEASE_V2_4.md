# EVO V2.4 — Public Asset Page

V2.4 turns the QR verification destination into a customer-facing asset page instead of a technical lookup screen.

The public view is read-only and combines existing EVO evidence: Seal identity, issuer trust, current ownership, lifecycle history, optional file fingerprint and public QR verification.

Commercial, creation, wallet and owner-management controls are hidden in QR mode. The technical record remains accessible on demand.
