Crear EVO Seal

V1 requiere una wallet EVM para firmar el sello. El archivo no se sube; sólo se registra su SHA-256 y metadata no sensible. V1 todavía no mueve EVO.

Resultado

Conectá una wallet y creá un sello.

Estado V1

Archivo: permanece local.

Identidad: wallet firmante.

Registro: público y consultable.

QR: abre la verificación pública.

Costo token: 0 EVO durante V1.

Verificar públicamente

La verificación de EVO permanece gratuita. Podés buscar un Seal ID desde cualquier navegador, escanear su QR y comparar opcionalmente el archivo original.

Estado

Ingresá un Seal ID.

Security Gate

No avanzamos a una fase que maneje valor hasta que la anterior pase sus controles.

V0 ✓: hashing local, detección original/modificado, sin transferencias.

V1: registro público + firma de wallet + verificación pública + QR.

Testnet: contrato mínimo, límites y pruebas automatizadas.

Mainnet: sólo después de revisión de seguridad independiente.
