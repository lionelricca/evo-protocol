Token design

EVO V2 is a fixed-supply ERC-20. The deployed token has no post-deployment mint function, no blacklist, no pause mechanism, no transfer tax, and no upgradeable proxy. The migration system exchanges legacy EVO for EVO V2 at 1:1 and retains migrated legacy tokens in the migration contract.

Migration

The current token replaces the previous EVO token on Polygon. Holders should verify contract addresses before interacting. This page does not request seed phrases, private keys, or wallet approvals.
